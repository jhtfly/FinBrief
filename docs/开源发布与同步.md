# 开源发布与同步流程

本仓库是 FinBrief 的开源发布仓库，由本地源码项目经**白名单同步**生成——个人数据、试用密匙台账、API 方案等永不进入本仓库。

## 目录来源

| 仓库内容 | 来源 |
|---|---|
| app/ web/ main.py build.spec requirements.txt assets/ tests/ | 源码项目同名文件（白名单复制） |
| README.md | 仓库专用版（项目介绍 + 使用手册合并） |
| docs/DEVELOPMENT.md | 源码项目 DEVELOPMENT.md 脱敏版（本机路径→相对路径） |
| LICENSE / .gitignore | 仓库专用 |

## 每次修改程序后的同步流程

1. 在源码项目（FinBrief/）改代码、测试、更新 DEVELOPMENT.md 与 README（程序侧使用手册）
2. 运行同步脚本：`python sync_open_source.py`（白名单复制 + 隐私审计 + 差异清单）
3. 审计输出必须 **0 命中**（个人姓名/QQ 邮箱/本机路径/密匙台账等关键词）
4. 到本目录提交推送：
   ```bash
   git add -A && git commit -m "vX.Y.Z: 简述" && git push origin main
   ```
5. 需要发版时：打包 zip → `gh release create vX.Y.Z` 上传资产

## 红线（永不入库）

- `data/`（运行数据库，含用户业务数据与密钥密文）
- `试用密匙库.json` 等密匙台账/管理工具（在交付目录，属管理员私有）
- 内置 RSSHub 运行环境（rsshub/、rsshub_bundle/，数百 MB，走 Release 附件）
- 本机绝对路径、个人姓名/邮箱（提交邮箱一律用 GitHub noreply）
