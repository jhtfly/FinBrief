# 金融热点编译系统 · 使用说明

一款在本地运行的信息聚合研究工具：自动检索境外机构公开信息，AI 参与整理归纳，人工复核定稿后按模板导出 Word。全流程数据保存在本机。

## 一、快速开始

1. **配置大模型 API**：进入「设置 → 大模型 API」，填写 OpenAI 兼容的 Base URL 与 API Key（支持 DeepSeek、通义千问、GLM 等主流服务商）。未配置 Key 时可先点「启用内置试用额度」直接体验；已填自定义 API 也可随时切换试用额度并一键还原。
2. **检索线索**：进入「线索面板」，点「开始检索」。境外站点较多，建议开启系统代理软件后再检索。
3. **AI 筛选**：检索完成点「⚡ 一键筛选」，AI 按六条筛选要求逐条判定（结果标在每条线索上）。
4. **编译专报**：单条线索点行内「编译」，或勾选多条点「一键编译 / ✦ 综合专报」，也可自己上传材料（「专报管理 → 自定义专报」）。成稿后进入编辑器人工复核，标题/正文/引用均可改，每一步自动存稿。
5. **导出 Word**：编辑器内点「编辑完成，导出 Word」，按模板自动排版（期号自动连续编号；可在设置切换「精简格式」，仅保留红色分隔线、不占期号）。

## 二、模块速览

| 模块 | 说明 |
|---|---|
| 线索面板 | 并发检索（站数可调）、一键筛选、标题自动翻译、AI 语义相关性检索（输入检索词，AI 直接判定窗口内线索标题与检索词强相关即返回）、只看未读、收藏等 |
| 热点方向 | AI 基于符合要求的线索归纳热点方向（排名/趋势/热度），全部方向直接展示；相关线索可多选（2-5 条）一键融合综合专报 |
| 专报管理 | 单篇 / 综合 / 自定义专报三页签；编辑 / AI 对话式修改（可撤销重做、前后对比可拖动）/ 引用校对 / 导出；支持按修改时间、期号、状态、标题排序与标题/机构/期号检索；已放弃条目同样可点标题跳原文 |
| 收藏夹 | 线索/专报收藏统一管理，可随时编译核对 |
| 线索数据库 | 全量线索检索与 AI 智能主题分类（胶囊标签可拖动排序，点击查看全部线索），支持单条/批量删除（已编译的拦截提示） |
| 信源管理 | 精选 / 全部 / 自定义三页签；每源可右键测试与查看详情；AI 自动添加站点；RSSHub 路由库（内置服务随程序启动，粘贴链接一键试连添加、路由目录挑路由、自动中文名） |
| 任务中心 | 全部后台任务状态、任务历史的失败明细直达卡片、运行日志 |
| 设置 | 大模型 API（opencode.ai 等服务商请求头已自动处理，无需手配）、网络与采集、自动检索与翻译（检索后自动补全缺失日期，可关）、评分权重、提示词、导出排版、界面外观、开源声明 |

## 三、常见问题

- **多站点失败** → 开启外置代理软件后重新检索。
- **API 429 / 空正文** → 程序已自动重试（次数可调）；仍失败稍后再试或更换模型/服务商。
- **试用额度用尽** → 在设置填自己的 API Key 即可。
- **再次编译同一线索** → 会提示已编译过；确认后旧草稿（含已导出的）将被新草稿替换。
- **AI 添加信源验证未通过** → 源已保存但停用并注明原因；强防护站点可开代理重试。
- **导出被占用** → 关闭正在查看该文件的 Word/WPS 后重试。
- **自动检索未触发** → 检查「自动检索」模式与时间设置。
- **手改 settings.json** → 需重启程序生效；文件为分区结构，键名请勿改写。

## 四、数据与隐私

全部数据保存在本机（data 目录），API Key 仅用于调用您配置的大模型接口，程序不内置任何用户密钥。升级程序仅替换文件，不会动运行目录中的数据与设置。程序输出为信息聚合与研究参考，不构成投资建议；专报发布前请人工复核定稿。

开源声明与使用须知见「设置」页底部。
