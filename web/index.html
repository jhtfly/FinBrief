自动检索

并发越高批量任务越快，也更占用网络与 API 额度。AI 并发请按服务商限流设定——例如"每分钟最多 10 次请求"的 API 建议 2；限流 429 就调小。模型响应迟缓/偶发断联时自动按指数退避（3s→6s→12s…）重试，4xx 密钥/参数错误不重试；重试过程记录在「运行日志」。
